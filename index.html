How it works

RuneLite writes banktags,<version>,<name>,<icon>,<items…> followed by layout,<position>,<item>… pairs. The official client wants 1,<item count> followed by <item>,<column>,<row> triples, where a bank position splits into position % 8 and position / 8 across the 8-wide bank grid. The tag name and icon are not carried by the string — set those in game when you make the tab.

Item images from static.runelite.net. Format cross-checked against the OSRS Wiki converter.
